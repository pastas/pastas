Pastas Sustaining Membership Program
====================================

Pastas is an open-source software project. The development and maintenance of Pastas, the code, the documentation, and examples depend in a large part on the voluntary work of the Pastas development team. Since the start of the project in 2016, Pastas has been developed into a Python package trusted by hundreds of organizations across the globe to efficiently analyze and model groundwater level time series. Free to use and improve for everybody.

Despite all the achievements made so far, funding is required to maintain Pastas and keep the software up-to-date. For this purpose, we call upon our community to contribute to this effort through our sustaining membership program. There are various ways to contribute, and we welcome all contributions, big and small. The funds raised through the sustaining membership program will be used to support the development and maintenance of Pastas, as well as to fund new features and improvements to the software.

How the funds will be used
--------------------------

- Keep the code up-to-date with new versions of Python and the Python packages that Pastas uses
- Fix bugs in Pastas and Pastastore
- Improve and extend documentation
- Interact with users, respond to GitHub Issues and Discussions
- Develop and improve the existing code base (i.e., new functions) to meet user needs
- In the future we hope to expand these activities to fund substantial improvements to the Pastas code base and documentation (i.e., new modules).

Sustaining memberships
----------------------

We will collect the sustaining membership contributions through `Open Collective <https://opencollective.com/pastas>`_. The contributions will be collected on an annual basis, and the amount of the contribution is up to you. We suggest contributions depending on the size of the organization, but any amount is welcome. You can also choose to contribute anonymously if you prefer. Go to https://opencollective.com/pastas

All members will be listed with their company logo on the sustaining members page (see below), unless anonymous membership is desired.
